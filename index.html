Class 12 Syllabus Reference

• Inverse Trigonometry: θ = arctan(h / x). Principal branch domain: (-π/2, π/2). Reconstructs elevation angle from raw geometric coordinates.

• Applications of Vector Algebra: Position vector r⃗ = x î + h ĵ. Modulus: |r⃗| = √(x² + h²) = x · sec(θ). Direction cosines: cos(α) = x/|r⃗|, cos(β) = h/|r⃗|.

• Differential Error Analysis: Total differential dh = tan(θ) dx + x sec²(θ) dθ. Models rapid error growth near 90°.
